# M365 Automation and Utility – Abhijit More

This repository contains automation solutions, Bulk Operations and useful scripts using PowerShell and Microsoft 365 services to improve operational efficiency, reduce manual effort, and enhance service reliability across enterprise environments.

## 🚀 Automations Included

### 1. License Reporting Automation
- Extracts license usage details from Microsoft 365
- Generates structured reports for license cleanup and optimization
- Helps track unused or underutilized licenses
- Reduces manual reporting effort

### 2. BitLocker Inventory Automation
- Retrieves BitLocker recovery keys from Microsoft Intune / Azure AD
- Maintains centralized device encryption inventory
- Supports compliance and security requirements
- Simplifies recovery key management

### 3. Exchange Online Lifecycle Automation (Graph + Certificate Based Authentication)
- Uses Microsoft Graph API with certificate-based authentication for secure, unattended execution
- Connects to Exchange Online and Azure AD without storing credentials
- Fetches users created within the last 7 days
- Automatically enables archive mailbox and auto-expanding archive
- Applies Litigation Hold for compliance and data retention
- Configures calendar permissions to limited visibility
- Ensures standardized mailbox configuration for all new users
- Reduces manual onboarding effort and enforces governance policies

### 4. Bulk Operations & Utility Scripts
- Bulk user updates and administrative actions
- Mailbox management scripts
- Group and permission handling
- Helps perform repetitive admin tasks efficiently
